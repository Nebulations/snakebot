# SnakeBot
SnakeBot is a neural network that uses pytorch to play the classic snake game.

## Requirements
- Python 3.13.14
## Instructions (Windows 11)
1. Clone the repository via `git clone https://github.com/Nebulations/snakebot`
2. Create a new python environment: `python -m venv .venv`
3. Run the new environment: `.\.venv\Scripts\activate`
4. Install the requirements.txt: `pip install -r requirements.txt`
5. Finally, run the model: `python .\main.py`

If everything goes accordingly, you should see a window pop up. Reduce or increase the framerate in `main.py`
